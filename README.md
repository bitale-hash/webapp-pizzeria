# 🍕 Pizzeria Web Application
Una piattaforma web moderna, completa e scalabile per la gestione di una pizzeria, sviluppata con **Next.js**, **TypeScript** e **Tailwind CSS** (o moduli CSS). 


  ## ⚙️ Guida all'Installazione e Avvio
Segui questi semplici passaggi per avviare il progetto in locale:

1. **Apri il tuo editor di codice** (es. *Visual Studio Code*).
2. **Apri il terminale integrato** assicurandoti di trovarti nella cartella principale del progetto (`webapp-pizzeria`).
3. **Esegui i comandi di installazione e avvio:**
   cd webapp-pizzeria
   npm install
   npm run dev
   (ctrl + left click) on the link :"http://localhost:3000"

   ## 🛠️ Requisiti di Sistema
Assicurati di avere installato sul tuo computer:
  - [Node.js](https://nodejs.org/) (versione LTS consigliata)
  - Un package manager compatibile come `npm`
